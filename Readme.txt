# 🚀 My Personal Portfolio Website

This is a personal portfolio website designed to showcase my skills, projects, and professional background as a UI Developer/Web Designer.


---

## 📱 Features
* **Responsive Design:** Completely optimized for mobile, tablet, and desktop screens.
* **Modern UI:** Clean typography, professional gradients, and a highly intuitive user-friendly layout.
* **Interactive Sections:** Immersive About Me layout, organized Project Showcase, Technical Skills matrix, and a fully functional Contact section.

---

## 🛠️ Tech Stack Used
* **Design & Wireframing:** Figma / Adobe Photoshop (for pixel-perfect mockups)
* **Core Frontend:** HTML5, CSS3, JavaScript, jQuery
* **Libraries & Frameworks:** Bootstrap, FontAwesome Icons, Google Fonts
